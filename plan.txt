 Tea Timer App for Garmin Venu 3 - Implementation Plan

 Overview

 Create a simple Garmin Connect IQ app that starts a 5-minute countdown timer automatically when launched.

 Technology Stack

 - Language: Monkey C
 - SDK: Garmin Connect IQ SDK
 - Target Device: Venu 3 (device ID: venu3)
 - App Type: Watch App

 Project Structure

 garmin-tea-timer/
 ├── manifest.xml          # App metadata, device targets, permissions
 ├── monkey.jungle         # Build configuration
 ├── resources/
 │   └── strings/
 │       └── strings.xml   # App name and strings
 └── source/
     ├── TeaTimerApp.mc    # App entry point (AppBase)
     ├── TeaTimerView.mc   # Main view (displays countdown)
     └── TeaTimerDelegate.mc  # Input delegate (minimal for now)

 Files to Create

 1. manifest.xml

 - App ID (UUID)
 - App name: "Tea Timer"
 - App type: "watch-app"
 - Target device: venu3
 - Min API level: 5.1.0 (Venu 3 requirement)

 2. monkey.jungle

 - Project name
 - Source file references
 - Resource references

 3. resources/strings/strings.xml

 - App name string

 4. source/TeaTimerApp.mc

 - Extends Application.AppBase
 - getInitialView() returns the timer view and delegate
 - onStart() initializes the timer

 5. source/TeaTimerView.mc

 - Extends WatchUi.View
 - Stores remaining time (starts at 300 seconds = 5 mins)
 - onUpdate(dc) draws:
   - Remaining time in MM:SS format
   - Centered on screen
 - decrementTime() method called by timer callback

 6. source/TeaTimerDelegate.mc

 - Extends WatchUi.BehaviorDelegate
 - Minimal implementation for now
 - onBack() exits the app

 Timer Logic

 1. Create a Timer.Timer instance in the App
 2. Start timer with 1-second interval: timer.start(callback, 1000, true)
 3. Each tick:
   - Decrement remaining seconds
   - Call WatchUi.requestUpdate() to refresh display
   - When reaching 0: stop timer, optionally vibrate

 Display Format

 ┌─────────────────┐
 │                 │
 │                 │
 │     04:32       │  <- MM:SS countdown
 │                 │
 │   Tea Timer     │  <- Optional label
 │                 │
 └─────────────────┘

 Implementation Steps

 3. Create monkey.jungle build config
 4. Create resources/strings/strings.xml
 5. Create TeaTimerApp.mc with timer initialization
 6. Create TeaTimerView.mc with countdown display
 7. Create TeaTimerDelegate.mc with back button handling

 Testing
