# Tea Timer App - Feature Enhancements

## User Experience Enhancements

### 1. Pause/Resume Functionality
Currently, once a timer starts, it can only be reset. Adding pause/resume would let users handle interruptions without losing their progress.

### 2. Custom Timer Durations
Allow users to adjust brewing time for each tea type. Not everyone brews green tea for exactly 2 minutes - some prefer 3-4 minutes for stronger flavor.

### 3. Audio Alerts
In addition to vibration, add optional sound alerts when the timer completes. Useful when the watch isn't on the wrist.

### 4. Favorite/Quick Access
If someone always uses one tea type, add a way to set a default that appears first, rather than cycling through all four types.

### 5. Brewing Temperature Indicator
Display recommended brewing temperature for each tea type (e.g., Green: 175°F, Earl Grey: 212°F). This is key information tea enthusiasts care about.

## Timer Management

### 6. Multiple Concurrent Timers
Support running multiple timers simultaneously (e.g., brewing green tea while steeping jasmine). Show a list view of active timers.

### 7. Repeat/Auto-restart
For multiple steepings (common with high-quality teas), add an option to automatically restart the timer after completion, possibly with decreasing durations for subsequent steeps.

### 8. Custom Tea Types
Let users add their own tea types with custom names, durations, colors, and icons. Currently limited to the 4 hardcoded types.

### 9. Steep Counter
Track how many times a tea has been steeped (useful for multiple infusions of the same leaves).

## Information & History

### 10. Brewing History/Log
Track what teas were brewed and when. Could provide insights into favorite teas or brewing patterns.

### 11. Brewing Notes
Allow simple notes per tea type (e.g., "2 min for weak, 3 min for strong") that display when selecting that tea.

### 12. Timer Presets
For teas that benefit from different steep times (like oolong with 30s, 45s, 1min, etc. for multiple infusions), store preset sequences.

## Most Impactful (Quick Wins)

If implementing just a few enhancements, these would provide the most value with reasonable effort:

1. **Custom timer durations** - dramatically increases usefulness
2. **Pause/resume** - common real-world need
3. **Brewing temperature display** - useful reference info without complexity
